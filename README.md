## Работа 1. Учёт результатов спортсменов (`Works/work1`)

### Сборка и запуск

* Windows (MinGW-w64):
```bash
cd Works/Work1
gcc -Wall -Wextra -std=c11 work1.c -o work1.exe
.\work1.exe
```

* Linux (GCC):
```bash
cd Works/Work1
gcc -Wall -Wextra -std=c11 work1.c -o work1
./work1
```

### Пример запуска
```
Введи количество спортсменов

Петя

20
Введи имя 3 спортсмена
```
